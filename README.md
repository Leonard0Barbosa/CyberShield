# CyberShield
O CyberShield: Academia do Hacker Ético é um jogo voltado para ensinar os conceitos básicos da cibersegurança.
Com o aumento nos últimos anos de golpes digitais, é necessário que as pessoas saibam como lidar com essas situações sem passar suas informações e dados pessoais para qualquer pessoa da internet.
O jogo irá colocar o jogador no papel de um estudante em um cenário onde foi contratado por uma empresa e deve procurar meios de evitar ameaças digitais, identificar possíveis golpes e proteger as informações da empresa.
